# Coffee-Shop-Sales-Analysis-Dashboard(Excel)
This project showcases an end-to-end data analysis workflow using Microsoft Excel, where raw transactional data from a coffee shop business is transformed into a fully interactive dashboard. The objective is to uncover sales patterns, customer behavior, and business insights to support data-driven decision-making.

## Dataset Description
The dataset contains detailed transaction-level information, including:
- Transaction Details: ID, Date, Time, Quantity
- Store Information: Store ID, Store Location (Astoria, Hell’s Kitchen, Lower Manhattan)
- Product Information: Category, Type, Product Name, Size
- Pricing: Unit Price, Total Sales

This structure enables multi-dimensional analysis across:
- Time (hourly, daily, monthly)
- Product performance
- Store location comparison

## Business Problem
Coffee shop chains generate large volumes of transactional data daily. However, without proper analysis, it becomes difficult to:
- Identify peak business hours
- Track top-performing products
- Compare store performance
- Optimize inventory and promotions

## Data Cleaning & Preparation
Data was cleaned and prepared in Excel by:
- Removing duplicates and handling missing values
- Standardizing date and time formats
- Creating calculated fields (Total Sales, Hour, Month, Day)
- Structuring data for pivot-based analysis

## Dashboard Features
The dashboard includes interactive and dynamic visualizations:
#### Key Metrics (KPIs)
- Total Revenue
- Total Orders
- Average Order per Person
- Average Order Value

#### Sales Analysis
- Sales trend by Month & Day
- Hourly sales distribution (peak time detection)

#### Product Insights
- Top-performing products (e.g., Latte, Cappuccino, Croissant) 
- Category-wise contribution (Coffee, Tea, Bakery, etc.)
  
#### Store Performance
Sales comparison across:
- Astoria
- Hell’s Kitchen
- Lower Manhattan 

## Key Insights
From the analysis:
- Coffee & Tea dominate sales, contributing the highest revenue 
- Bakery items (croissants, scones, biscotti) are frequently purchased with beverages
- Sales peak during morning and early afternoon hours (rush hours)
- Certain store locations outperform others in total revenue
- Strong product combinations indicate cross-selling opportunities

## Business Recommendations
Based on insights:
- Increase staffing during peak hours
- Bundle coffee + bakery combos to increase average order value
- Focus promotions on top-performing products
- Optimize inventory based on high-demand items and time patterns
- Benchmark store performance to improve underperforming locations
